# heatsim
heatsim is a Python project to simulate the heat equation for different target media at the European Spallation Source.

## Contact
heatsim is developed in connection to a Master Thesis project at ESS and the LTH. The people involved in the project are listed below:
 - Axel Isakson, MSc in Engineering Physics, LTH
 - Cyrille Thomas, Supervisor, ESS
 - Eskil Hansen, Supervisor, LTH


## Installation

To use heatsim, simply clone the repo and use package manager pip to install dependencies. 
```bash 
pip install -r requirements.txt
```
